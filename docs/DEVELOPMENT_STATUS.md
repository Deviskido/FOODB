# FOODB 개발한 부분과 남은 부분

기준일: 2026-11-18

## 1. 현재 상태

**MVP 필수 기능을 구현했고, 패키지 설치 없이 실행하는 Node 버전의 검증 명령이 통과했습니다. 실제 브라우저 인수 검사는 남아 있습니다.**

최소 흐름은 `입고 → 측정·품질 판정 → 고정 레시피 승인 → 예약 → 생산 → 완제품 재고`입니다. 기존 전체 기획의 라이선스·배송·장비·자동 조정은 MVP 필수 범위에서 제외하고 보존했습니다.

실행: `npm run start:mvp` → `http://127.0.0.1:3000`

## 2. 개발 완료한 MVP 기능

| 영역 | 구현한 내용 |
| --- | --- |
| 실행 | Node 26 내장 SQLite, 외부 패키지 없는 최소 화면, `doctor`·`verify:mvp`·Windows 런처 |
| 기본 화면 | 한국어 단계별 단일 작업대, 재고·생산 상태, 새로고침, 로그인·로그아웃 |
| 초기 설정 | 조직·소유자 생성, 작업자·역할, 운영 데이터 보관 정책 |
| 입고·재고 | kg 입력, 정수 mg 저장, 보유·예약·가용량, 안전 보류 |
| 측정·품질 | °Bx/pH 수동 측정, 단위·불확실성·유효시간, 기준 작성·승인, 판정 저장 |
| 레시피 | 단일 원료 고정 레시피, 작업 지시·알레르기·예상 수율, 승인 |
| 생산 준비 | 최신 원료·레시피 확인, 투입량 예약과 배치 생성의 원자적 처리 |
| 생산 실행 | 시작 시 권한·품질·보류 재확인, 재고 소비, 단계별 실제 기록, 차이 발생 시 보류 |
| 완료·취소 | 실제 수율·공정 손실·완제품 원료 계보, 시작 전 취소 시 예약 반환 |
| 보호 | 조직별 데이터·DB 외래키, 비공개 지시 접근 제한, salted scrypt 비밀번호, 세션·감사 기록 |
| 운영 | 계정 추가, 운영 데이터 내보내기, 백업·복원 도메인 및 기존 CLI |

Node와 Bun은 같은 도메인 API·스키마를 공유합니다. 새 비밀번호 형식은 두 런타임에서 사용 가능합니다. 기존 Bun 전용 해시가 있는 데이터는 Bun으로 열어야 하므로 기본 데이터 디렉터리를 분리했습니다.

## 3. 실제 검증한 것

- `npm run verify:mvp`: **성공**.
- 테스트 **32개 통과 / 0개 실패**.
- Node **26.5.0**, 실제 `node:sqlite`와 암호화 API 사용. DB·암호화 목업 없음.
- MVP 정상 흐름, 재시도, 예약 취소, 보류·만료·리비전 충돌, 최신 품질 판정 변경 시 시작 차단, 조직 격리.
- 배치 쓰기 실패를 주입해 승인 스냅샷·예약·감사 효과가 함께 롤백됨을 확인.
- 복원 세션 무효화·삭제 지시 재적용·복원 보류, 증빙 접근 차단.
- Node 최소 화면 파일과 API 응답, JavaScript 문법 검사.
- 서버 시작 실패 시 잠금 파일 정리.

32개 중 일부는 보존된 확장 도메인의 회귀 검사입니다. 확장 기능 전체가 상용 완성됐다는 뜻은 아닙니다. 예전 Node 호환 하네스 로그는 역사적 기록이며, 최신 네이티브 결과는 별도 파일에 있습니다.

## 4. 남은 작업

### P0 — MVP 브라우저 인수

1. 사용자 터미널에서 `npm run start:mvp` 실행 후 초기 설정부터 생산 완료까지 실제 조작.
2. 새로고침·로그아웃·재시작 후 데이터 유지와 보류/오류 메시지 확인.
3. 모바일 390×844 / 데스크톱 1440×1000, 밝은/어두운 테마와 키보드 조작 확인.
4. Windows 배포가 필요하면 `start-mvp.cmd` 실행.

현재 세션의 포트 바인딩은 `EPERM`으로 실패했습니다. Chrome은 실행 직후 `SIGABRT`로 종료되어 화면 검사를 수행하지 못했습니다. **실제 브라우저를 검증했다고 표시하지 않습니다.** Node MVP 실행에는 Bun이나 npm 레지스트리 연결이 필요하지 않습니다.

### P1 — 현장 사용성·운영 고도화

- 작업 지시·입력 오류 메시지에 대한 현장 피드백 반영.
- 대량 기록 검색과 페이지 분할, MVP 요약 화면 부하 측정.
- 시간·온도·공정 제한의 구조화, 알레르기 및 대체 원료 검토.
- 백업·복원 운영 리허설, 자동 백업과 보관·삭제 관리 확대.
- 조직 전환·역할 분리 승인 UI와 관리 기능 고도화.

### P2 — 기존 확장판 개발

- React/Bun 의존성 설치·버전 고정·타입 검사·컴파일·실제 화면 검증.
- 자동 레시피 조정의 불확실성 전파와 정책 작성 UI.
- 모델·품질 기준·레시피 롤백, 계측 모델 모니터링 화면.
- 다중 원료, 개수↔질량 환산, 복잡한 계보 관리.
- 콘텐츠 사용권에 따른 파생·출판·내보내기 실행.
- 라이선스·청구 조정, 포장 단위·배송 조건, 경제성·관능 분석.
- 실제 측정 장비·로봇·배송 시스템 연동과 물리 시험.

확장 기능 일부는 기존 코드와 테스트가 있지만 모두 MVP 기본 화면에 노출하지 않습니다. 세부 요구사항 표는 [requirements.md](requirements.md)를 참고하세요.
